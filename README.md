# Mini Shop – Assignments 1, 2 & 3

A tiny online shop (3 products, fake card payments) with:

- an HTTP API (`app/main.py`) and a gRPC service (`app/grpc_server.py`) sharing the same rules (`app/shop.py`) and the same SQLite database;
- Prometheus + Grafana + Node Exporter for metrics;
- Filebeat + Elasticsearch + Kibana for JSON logs;
- three replicas (A, B, C) behind an Envoy load balancer (Assignment 3).

Report: [REPORT-A3.md](REPORT-A3.md) (load balancing).

## Start

```bash
docker compose up -d --build
pip install -r scripts/requirements.txt      # for the clients, traffic and tests
```

If you ran the Assignment 1 version before, run `docker compose down -v` once first (the orders table gained a column).

| What | URL |
|---|---|
| **Shop website** (buy, pay, cancel) | **http://localhost:8000** |
| Shop HTTP API | http://localhost:8000/products, /orders, ... |
| API docs (Swagger UI / OpenAPI) | http://localhost:8000/docs, http://localhost:8000/openapi.yaml |
| Shop gRPC | localhost:50051 |
| Envoy admin (clusters, health, stats) | http://localhost:9901/clusters |

| Grafana dashboards | http://localhost:3000/d/shop/shop, http://localhost:3000/d/lb/load-balancing-a3 |

## Use

Open **http://localhost:8000** in a browser: pick a product, enter a quantity and a card number, pay, and cancel orders under "Your orders". The page (`app/static/index.html`) is plain HTML/JavaScript that calls the HTTP API below.

Same thing from the command line:

```bash
curl http://localhost:8000/products
curl -X POST http://localhost:8000/orders -H "Content-Type: application/json" \
     -H "Idempotency-Key: my-key-1" -d '{"product_id": 1, "quantity": 2, "card": "4242424242424242"}'
curl http://localhost:8000/orders/1
curl -X POST http://localhost:8000/orders/1/cancel

python clients/grpc_client.py --product-id 1 --quantity 2 --card 4242424242424242
```

Cards starting with `4000` are declined by the fake payment provider.

## Test

```bash
pytest tests -v                         # valid, invalid, repeated, declined, rate limit, gRPC
python clients/order_caller.py          # timeout / retry / circuit breaker demo
python scripts/traffic.py --seconds 120 # repeatable HTTP + gRPC traffic for the dashboards
```

Rate limit demo (30 orders per 10 s per IP; the 31st gets `429` + `Retry-After`):

```bash
for i in $(seq 1 32); do curl -s -o /dev/null -w "%{http_code} " -X POST http://localhost:8000/orders \
  -H "Content-Type: application/json" -d '{"product_id":2,"quantity":1,"card":"4242424242424242"}'; done
```

Fault injection (the HTTP order endpoint):

```bash
curl -X POST "http://localhost:8000/admin/fault?delay_ms=500&every=5"   # every 5th order waits 500 ms
curl -X POST "http://localhost:8000/admin/fault?fail_next=3"            # next 3 orders return 503
curl -X POST "http://localhost:8000/admin/fault"                        # all off
```

Cardinality experiment (Prometheus job `demo`):

```bash
python scripts/cardinality_demo.py --with-id   # 100 series, Ctrl+C after a few scrapes
python scripts/cardinality_demo.py             # 1 series
```

Regenerate gRPC code after changing `proto/orders.proto`:

```bash
python -m grpc_tools.protoc -I proto --python_out=app --grpc_python_out=app proto/orders.proto
```

Kibana: create a data view for `filebeat-*` (Stack Management → Data Views), then use Discover.

## Load balancing (Assignment 3)

All traffic on ports 8000 (HTTP) and 50051 (gRPC) goes through **Envoy** to three replicas
`esd-shop-1/2/3` = **A/B/C** (`docker compose` scaling, `deploy.replicas: 3`). Envoy's config
`envoy/envoy.json` is generated by a script:

```bash
python scripts/envoy_config.py a-only          # only A gets traffic (B, C idle)
python scripts/envoy_config.py round-robin     # A, B, C equal
python scripts/envoy_config.py weighted        # A:B:C = 2:1:1
python scripts/envoy_config.py least-request   # A, B, C, least request
docker compose restart envoy                   # apply it
```

Fixed-rate test (20 req/s per interface for 60 s, HTTP `GET /orders/{id}` and gRPC `GetOrder`,
no retries; results appended to `results/runs.jsonl`):

```bash
python scripts/loadtest.py --rate 20 --seconds 60 --label my-run
```

Experiments:

```bash
python scripts/delay.py B 200                  # B waits 200 ms per request (HTTP and gRPC)
python scripts/delay.py B 0                    # recover
docker stop esd-shop-2                         # B fails
docker start esd-shop-2                        # B recovers
```

Restore normal: `python scripts/delay.py B 0`, `docker start esd-shop-2`,
`python scripts/envoy_config.py round-robin`, `docker compose restart envoy`.

Note: the `/admin/fault` URLs above go through Envoy, so with several replicas they reach only
one of them; use `scripts/delay.py` (talks to one replica directly) or the `a-only` setup.

## Clean up

```bash
docker compose down          # stop, keep data
docker compose down -v       # stop and delete all data volumes (orders, metrics, logs)
```

If you used the stack before Assignment 3 (project name `esd-assignment1-2`), its old volumes can
be removed with `docker compose -p esd-assignment1-2 down -v`.
